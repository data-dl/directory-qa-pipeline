# demo/

Everything here is generated by `python -m synth --out demo` from a fixed seed, so it
can be deleted and rebuilt byte-for-byte. Nothing is real.

| Path | What it is | Committed? |
|---|---|---|
| `sources/PractitionerFeed.sqlite` | current-month professional source (`ProfessionalProviderSource`) | no |
| `sources/ServiceVendorFeed.sqlite` | current-month service sources (`AdditionalServiceSource`, `OtherFacilityReference`, `ManagedCareFacilitySource`) | no |
| `DirectoryQualityHub.sqlite` | the repository as the cycle begins: last month's cleaned directories, this month's staged pharmacy table, the approved deletion list | no |
| `archive/2026-08/*.csv` | last month's tables, for the prior-month comparison | no |
| `csv/2026-09/*.csv` | this month's source tables, for opening in Excel | no |
| `samples/*.csv` | the first 40 rows of each table, so the shape is visible without generating | yes |
| `advisory_checklist.csv` | the informal notes spreadsheet, as natural-language rows | yes |
| `answer_key.json` | every planted defect and change, by record id and stable key | yes |

The answer key is what the pipeline is graded against: each planted duplicate group,
missing field, malformed value, retired-source row and vanished borough is listed with
the record ids that carry it.
